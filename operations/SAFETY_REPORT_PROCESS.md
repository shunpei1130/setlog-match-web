# 通報対応手順

1. 新規通報は`open`で受け付け、ペアとSetlog情報を即時非表示にする。
2. 運営者が内容を確認し、初動と確認事項を運営メモへ記録して`reviewed`へ変更する。
3. 差し迫った危険、犯罪、けがは110／119を案内する。運営だけで判断しない。
4. 必要なアクセス停止、再推薦防止、当事者への個別連絡を行う。相手に通報者や通報内容を開示しない。
5. 対応内容と再発防止を運営メモへ記録し、`resolved`へ変更する。
6. 誤操作や追加情報で再確認が必要な場合だけ`open`へ戻す。

重大案件の最終判断は長谷川峻平が行う。Codexは候補案、競合チェック、返信文面を準備するが、被害者・通報者への最終送信を自動化しない。
